# Музыкальные игры у Машеньки и Лёшика — проект

Домашняя музыкально-комедийная парти-игра в духе шоу «Студия Союз»: телевизор — общий экран с заданиями, игроки отвечают с телефонов, один ведущий ведёт партию. Играется дома, общий экран показывается на телевизоре (трансляция с ноутбука).

## Название и стиль

- Рабочее имя проекта: **«Музыкальные игры у Машеньки и Лёшика»**.
- Визуальный стиль — в духе «Студии Союз»: тёплая золотая сцена, блёстки, тяжёлая заголовочная типографика, полоса-акцент. Красный — только небольшим акцентом. Без копирования их логотипа — название и логотип свои.

## Роли

- **Ведущий** (1 человек) — управляет партией с экрана ведущего.
- **Участники** (2+) — отвечают с телефонов. Два режима: «каждый сам за себя» (участник = человек) и «команды» (участник = команда, один телефон на команду).

## Эксперименты (7)

| # | Эксперимент | Суть | Тип | Медиа |
|---|---|---|---|---|
| 1 | Что ты такое? | угадать «гибридное» имя знаменитости (коллаж двух фото) | викторина | картинка |
| 2 | Нарисуй песню | один рисует на телефоне, остальные угадывают песню | креатив | нет |
| 3 | Никто поёт | старый клип без звука — кто из троих пел | викторина | клип (без звука) |
| 4 | Клипобол | отрывок клипа — что дальше (4 варианта) | викторина | клип |
| 5 | Караоке квиз | вопросы с двумя вариантами между строками песни | викторина | караоке |
| 6 | Я роняю шлягер | угадать шлягер по каверу-мамбл-рэпу | викторина | аудио |
| 7 | Косплей | три клипа — у какого реальный прототип | викторина | клипы |

Вне объёма (физические/голосовые): Сумооке, Цветомузыка, Караоке-машина, Вы двигаетесь великолепно, Повторение мать его. Правила не найдены: Математическое караоке, Рассинхронный перевод.

## Скоринг

- Викторины с правильным ответом — балл начисляется автоматически (плюс бонус за скорость по желанию).
- Выступления/креатив (Нарисуй песню, Косплей) — балл начисляет ведущий кнопкой «засчитать».
- В конце партии — победитель по сумме баллов.

## Медиа

- Источник по умолчанию — **YouTube** (клип/трек вставляется по названию).
- Позже — **локальные MP3**: ведущий кладёт файлы в папку/загружает список, игра играет их без интернета.

## Архитектура (см. ADR-0001)

Jackbox-подобная клиент-серверная схема: локальный веб-сервер на ноутбуке; общий экран и экран ведущего и пульты — браузеры в одной Wi-Fi сети; синхронизация в реальном времени по WebSocket. Внешний интернет нужен только для YouTube-медиа.

## План сборки

Собираются все 7 экспериментов сразу. Порядок внутренней работы — по мере готовности контента; общая обвязка (меню, роли, связка экранов, скоринг, медиа) — первым слоем под все эксперименты.
