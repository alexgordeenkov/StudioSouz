# Каталог игр шоу

Сопоставление «название игры в шоу» → `id` формата приложения. Перед использованием сверять каждый `id` с реальной регистрацией в `src/experiments/index.js` (источник истины — код).

| Название в шоу | id формата | Примечание |
|---|---|---|
| LSDЦЛ | `what-is-it` | коллажи фото+предмет |
| Рэп против политики | `rap-vs-politics` | цитата → рэп/политика |
| Песня о песне | `song-about-song` | пародия → оригинал |
| Перепесня | `song-about-song` | тот же механик, что «Песня о песне» |
| Унижай мелодию | `degrade-melody` | необычный звук → песня |
| Переперевод | `retranslation` | искажённый текст → оригинал |
| Кто это наделал? | `who-did-this` | клип без звука → песня |
| Нарисуй песню | `draw-song` | рисование (не квиз) |

## Вне объёма (пропускать)

Физические/голосовые и ненайденные правила: Один раз не Костюшкин, Экстремальное караоке, Повторение мать его, Сумооке, Цветомузыка, Караоке-машина, Вы двигаетесь великолепно, Математическое караоке, Рассинхронный перевод.
