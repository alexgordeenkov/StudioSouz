## Пайплайн извлечения

```powershell
# субтитры
python -m yt_dlp --skip-download --write-auto-subs --sub-langs ru --sub-format vtt -o "<name>" "<url>"
# сегмент видео (720p)
python -m yt_dlp --ffmpeg-location "<dir-with-ffmpeg>" -f "bv*[height<=720]/b[height<=720]" --download-sections "*00:04:00-00:09:10" -o "seg.mp4" "<url>"
# контактный лист (кадр каждые 5 с, сетка 5x4)
ffmpeg -i seg.mp4 -vf "fps=1/5,scale=360:-1,tile=5x4" sheet_%03d.jpg
# кадр + обрезка карточки коллажа (без подписи снизу)
ffmpeg -ss <t> -i seg.mp4 -frames:v 1 f.jpg
ffmpeg -i f.jpg -vf "crop=380:470:50:40" out.jpg
```

Каталог карточки в кадре 1280×720: `x=50, y=40, w=380, h=470` (низ обрезается, чтобы не попала подпись-ответ).
