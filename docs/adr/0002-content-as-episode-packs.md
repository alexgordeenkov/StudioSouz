# Контент как набор выпусков

Контент игры привязан к выпускам шоу: каждый выпуск — пакет раундов для экспериментов, которые в нём были, а эксперимент остаётся форматом (id, название, правила, проверка ответа) без встроенных раундов. В меню ведущего видны только игры, у которых есть раунды в выбранном выпуске.

Considered Options: один общий пул раундов на игру (отклонён — теряется привязка к выпуску и «дословность»); контент, зашитый в модули экспериментов (отклонён — нельзя переключать выпуски).

Consequences: выпуск переключается только в лобби и сбрасывает раунды; новый контент — это новый пакет выпуска, а не правка эксперимента.
