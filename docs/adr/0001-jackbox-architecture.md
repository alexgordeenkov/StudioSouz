# Jackbox-подобная клиент-серверная архитектура

Парти-игра показывается на телевизоре, а игроки вводят ответы приватно (печатают, рисуют, жмут кнопку быстрее соперника). Один экран-«хотсит» это не решает — нужен общий экран плюс приватный ввод с каждого телефона. Поэтому принята Jackbox-подобная схема: на ноутбуке крутится локальный веб-сервер, общий экран (телевизор), экран ведущего и пульты участников — это браузеры, открытые в одной Wi-Fi сети; состояние синхронизируется по WebSocket в реальном времени.

Considered Options: единый экран на одном устройстве (отклонён — нет приватного ввода и бузера на скорость); облачный сервер с комнатами (отклонён — не нужен интернет-бэкенд для домашней игры, лишняя зависимость).

Consequences: сервер локальный и безинтернетный, внешняя сеть нужна только для YouTube-медиа; все устройства должны быть в одной Wi-Fi сети.
